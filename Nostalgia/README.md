# Nostalgia

**Nostalgia**는 서로 다른 역할을 가진 두 플레이어가 협력해 스테이지를 진행하는 온라인 협동 공포 게임입니다.

이 폴더에는 프로젝트에서 직접 설계하고 구현한 시스템 중, 게임 프로그래밍 역량을 보여줄 수 있는 핵심 코드 샘플을 정리합니다.

## Code Samples

### [ProceduralMap](./ProceduralMap)
플레이마다 달라지는 스테이지를 구성하기 위한 절차적 맵 생성 로직입니다.

- 타일을 조합하여 스테이지 구조 생성
- 생성된 맵을 기준으로 플레이에 필요한 오브젝트 배치
- NavMesh와 연계한 이동 가능한 스테이지 구성

### [MonsterAI](./MonsterAI)
몬스터의 상태와 추격 행동을 관리하는 AI 구조입니다.

- Idle / Alert / Chase 등 상태 기반 행동 관리
- NavMesh를 이용한 이동 및 추격
- 상태 전환 기준과 실제 행동 로직 분리

### [Multiplayer](./Multiplayer)
Photon Fusion 2를 이용한 멀티플레이 세션 및 게임 상태 동기화 코드입니다.

- 멀티플레이 세션 구성
- 네트워크 환경에서의 플레이어 및 게임 상태 동기화
- 권한을 기준으로 상태 변경 주체를 명확히 하는 구조

## Tech Stack

- C#
- Unity
- Photon Fusion 2
- NavMesh

## Note

본 저장소에는 전체 프로젝트가 아닌 핵심 구현 코드만 선별하여 포함합니다. 프로젝트 종속 에셋과 일부 연결 코드는 생략될 수 있습니다.
