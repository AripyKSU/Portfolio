# MagRog

**MagRog**는 마법 덱을 구성하고 다양한 조건과 효과를 조합해 전투를 진행하는 로그라이크 전략 게임입니다.

이 폴더에는 새로운 마법과 상태 효과를 쉽게 확장할 수 있도록 설계한 핵심 게임플레이 시스템 코드를 정리합니다.

## Code Samples

### [MagicSystem](./MagicSystem)
마법을 하나의 고정된 클래스에 작성하지 않고, 여러 기능을 조합해 구성할 수 있도록 만든 시스템입니다.

- `TargetSelector` : 효과를 적용할 대상 선택
- `Condition` : 마법이 발동할 조건 판단
- `Effect` : 실제 게임 상태에 적용할 효과 정의
- 각 요소를 ScriptableObject로 분리하여 조합 가능한 구조 구성

이를 통해 새로운 마법을 추가할 때 기존 실행 코드를 크게 수정하지 않고 데이터와 기능 조합으로 확장할 수 있도록 설계했습니다.

### [StatusSystem](./StatusSystem)
전투 중 발생하는 상태와 상태 효과를 관리하기 위한 시스템입니다.

- 상태 데이터와 실제 처리 로직 분리
- 마법 시스템과 연계 가능한 구조
- 새로운 상태 효과를 추가하기 쉬운 확장 구조 지향
